| 2026-09-21 | remark-language-server hosts realtime diagnostics in phase 1; dedicated LSP is the end state | fastest path to editor diagnostics; validator core is transport-independent |
| 2026-09-21 | Relation directions fixed per type in the vocabulary; no per-relation direction config | deterministic cycle detection (MDL305); one definition of each type |
| 2026-09-21 | `apply_metadata_patch` is the only path from proposal to Front Matter | LLM output never writes authoritative metadata directly |
| 2026-09-22 | MDL305 reports once per strongly-connected component (anchored on the lexicographically smallest path) | naive simple-cycle enumeration is exponential; a 20-document sparse ring must not OOM the CI gate |
| 2026-09-22 | Baseline suppressions are fully silent (no info-level echo) | prevent "ignore fatigue"; baseline diff trail is recorded via `baseline verify` mismatches instead |
| 2026-09-22 | `baseline verify`/`update` anchor on the repository root (`git rev-parse --show-toplevel`) | a sub-directory CI step must never bypass the gate by scanning only its subtree |
| 2026-09-22 | `selfReference: forbidden` is enforced at the workspace layer and reported as MDL103 | the config switch existed in M0 but had no enforcement point |
| 2026-09-22 | Heading slugs are byte-for-byte github-slugger parity (derived interval table, combining marks kept) | evidence anchors are authored from GitHub's rendering; a Unicode-interval approximation misjudged legal anchors |
| 2026-09-23 | LSP sync contract declared explicitly (openClose/change/save) per LSP 3.17 | an absent `change` means None, so a strict client would never push didOpen/didChange |
| 2026-09-23 | Rename onto an already-claimed id is refused with an error | applying the edit would fabricate MDL301 in every touched file |
