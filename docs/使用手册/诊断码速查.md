# 诊断码速查手册（MDL001–MDL903）

MDLineage 报告的每个质量或结构问题均携带全局唯一的 `MDLxxx` 诊断码。诊断码与严重级别属于版本化的稳定契约，严重级别可通过 `mdlineage.config.yaml` 的 `diagnostics:` 块进行项目级覆盖。

相关文档：[`使用指南.md`](./使用指南.md)（功能全景）、[`关系撰写指南.md`](./关系撰写指南.md)（血缘与锚点撰写）、[`配置指南.md`](./配置指南.md)（配置项说明）、[`命令行参考.md`](./命令行参考.md)（CLI 选项）。

## 1. 诊断码总表（33 个完整清单）

| **MDL002** | error | 头部结构 | 否 | Front Matter YAML 语法解析失败 |
| **MDL003** | error | 头部结构 | 否 | `metadata.required` 开启时缺少元数据（无 Front Matter 且无清单条目） |
| **MDL101** | error | 元数据模式 | 否 | 不支持的元数据 Schema 版本（仅支持 `schema: 1`） |
| **MDL102** | error | 元数据模式 | **是** | 缺少必填元数据字段（如 `id`、`kind`、`status`） |
| **MDL103** | error | 元数据模式 | 部分 | 字段类型、正则表达式或词汇表取值非法 |
| **MDL104** | error | 元数据模式 | 否 | `mdlineage` 块内包含未知非法字段 |
| **MDL105** | warning | 元数据模式 | 否 | 文档同时声明了 Front Matter 与清单条目（清单条目被忽略） |
| **MDL201** | warning | 单文档语义 | 否 | 自指关系的 evidence 锚点在本文档内不存在；跨文档 evidence 见 MDL402 |
| **MDL202** | warning | 单文档语义 | **是** | 单文档内声明了逐字节重复的关系条目 |
| **MDL203** | warning | 单文档语义 | 否 | 同页链接的标题锚点片段不存在 |
| **MDL301** | error | 工作区拓扑 | 否 | 全仓存在重复的文档 ID |
| **MDL302** | error | 工作区拓扑 | 否 | 关系依赖的目标文档 ID 不存在 |
| **MDL303** | error | 工作区拓扑 | — | 关系目标 ID 存在歧义（保留；纯 ID 解析下不可达） |
| **MDL304** | warning | 工作区拓扑 | 否 | 强关系类型的 `reason` 理由为空 |
| **MDL305** | error | 工作区拓扑 | 否 | 禁止成环的关系类型形成了循环依赖环路 |
| **MDL306** | warning | 工作区拓扑 | 否 | 活跃文档通过强关系引用了已废弃（deprecated）的目标 |

| **MDL308** | hint | 工作区语义 | 否 | 关系目标可能位于缺失的联邦成员仓库内（`missing: warn` 延迟诊断） |
| **MDL401** | warning | 超链接层 | 否 | Markdown 相对链接目标文件路径不存在 |
| **MDL402** | warning | 超链接层 | 否 | 跨文档引用的标题锚点片段不存在，或代码行号锚点越界 |
| **MDL403** | warning | 超链接层 | 否 | 引用了不可移植或不存在的 Linux 宿主路径（`~/...`） |
| **MDL501** | warning | 目录规范 | 否 | 违反基础目录约束（forbidStatus、require 限制） |
| **MDL502** | warning | 目录规范 | 否 | 文档放错目录（`kind`/`authority` 违背目录 intent） |
| **MDL503** | error | 目录规范 | 否 | 目录意图临时豁免例外（`layoutExceptions`）已过期 |

## 2. 核心诊断码排查与修复指引

### MDL0xx：头部语法与解析
- **`MDL001`（未闭合）**：开头的 `---` 缺少配对的结束 `---`。修复：补齐闭合的 `---` 分隔线。
- **`MDL002`（YAML 损坏）**：YAML 存在缩进错误、包含 Tab 制表符等。修复：检查 YAML 缩进格式。
- **`MDL003`（缺少元数据）**：开启强制检查后文档缺少 Front Matter。修复：运行 `mdlineage fix --write` 自动注入基础骨架，或在 `mdlineage.manifest.yaml` 中旁路登记。

### MDL1xx：模式契约与字段
- **`MDL102`（缺少必填字段）**：缺少必填的 `id`、`kind`、`status` 或强关系的 `reason`。修复：运行 `mdlineage fix --write` 自动从词汇表中插入默认合法值。
- **`MDL103`（取值超出词汇表）**：例如将 `kind` 写成了词汇表之外的值。修复：修改为词汇表允许的类别。
- **`MDL104`（未知字段）**：`mdlineage` 块内拼写错误（如手误写成 `tpoics:`）。修复：纠正字段拼写或从块内移除。
- **`MDL105`（Front Matter 与清单冲突）**：文档自身已包含 `mdlineage` Front Matter，外部清单又登记了同路径条目。Front Matter 优先，清单条目被忽略。修复：若以 Front Matter 为准，从清单中删除该条目；若以清单为准，删除文档内的 Front Matter 块。

### MDL2xx：文档内部语义与锚点
- **`MDL201`（证据锚点缺失）**：自指关系的 `evidence: "#some-anchor"` 在本文档内找不到对应的标题（跨文档 evidence 见 MDL402）。修复：更新为真实存在的标题 slug。
- **`MDL202`（重复关系）**：同文档内出现了两条完全相同的关系条目。修复：运行 `mdlineage fix --write` 自动删除重复项。
- **`MDL203`（同页锚点死链）**：正文中的 `[返回顶部](#top)` 找不到 `#top` 标题。修复：修正为文档实际存在的标题。

### MDL3xx：跨文件拓扑与血缘
- **`MDL301`（ID 重复）**：全仓有两篇文档使用了相同的稳定 `id`。修复：为冲突文档分配新的唯一 ID。
- **`MDL302`（目标丢失）**：关系声明的 `target: some.id` 在全仓索引中不存在。修复：纠正目标 ID 或补建缺失文档。
- **`MDL305`（循环依赖）**：禁止成环的关系类型（如 `supersedes`）形成了调用死循环。修复：解除环路上不合理的反向声明。
- **`MDL306`（引用废弃目标）**：活跃文档依赖了已被标记为 `deprecated` 的老旧文档。修复：迁移依赖至新替代文档，或推动更新。
- **`MDL307`（联邦目标歧义）**：使用 `@*//id` 全联邦通配寻址时，多个仓声明了同名 ID。修复：改为精准信封寻址 `@scope//id`，或使用裸 ID 指向当前仓。
- **`MDL308`（联邦成员缺失延迟提示）**：关系引用了被标记为 `missing: warn` 的缺失外部成员文档。修复：检出对应成员仓库，或待成员仓就绪后自动闭合。

### MDL4xx：超链接与宿主路径
- **`MDL401`（死链）**：相对路径链接目标文件不存在。修复：纠正路径或运行 `mdlineage move` 自动重写自愈。
- **`MDL402`（跨文档标题锚点或代码行号失效）**：链接 `[章节](./foo.md#bar)` 在目标文件内找不到 `#bar`；或代码链接 `[实现](./src/app.ts#L100)` 行号超出源码实际总行数。修复：对齐目标标题的 slug，或校准代码实际行号。
- **`MDL403`（宿主路径不可移植）**：使用了 `~/projects/...` 依赖本机的绝对路径。修复：改为工作区内的标准相对路径（`../`）。

### MDL5xx：目录规范与意图契约
- **`MDL502`（放错目录）**：例如将 `kind: spec` 的规范文件直接丢在要求 `kinds: [guide]` 的 `使用手册/` 下。修复：运行 `mdlineage move` 搬迁至匹配的目录。
- **`MDL503`（例外过期）**：在 `layoutExceptions` 中配置的临时豁免已过截止日期。修复：完成迁移并移除例外，或重新评估展期。
- **`MDL504`（约束超限）**：文件名不符合命名正则，或目录嵌套过深。修复：规范文件名或上提目录层级。
- **`MDL505`（孤儿文件）**：散落在未声明意图的根目录下。修复：归纳进对应的规范目录中。

### MDL6xx：行尾符卫生
- **`MDL601`（混合换行符）** 与 **`MDL602`（不符合策略）**：文件内夹杂 CRLF/LF，或与仓库策略不符。修复：运行 `mdlineage fix --write` 一键整仓归一。

### MDL8xx：生命周期与时效
- **`MDL801`（文档陈旧）**：文档超过 `staleAfterDays` 未曾更新。修复：复核正文事实后刷新 `updated_at` 时间戳；若已结项则标记 `status: archived` 移入 `历史归档/`。

### MDL9xx：联邦与配置完整性
- **`MDL901`（联邦声明环路）**：多个仓库间的 `federations` 形成了有向循环依赖链（例如 A 声明 B，B 声明 A，或成员又声明主仓）。修复：消除闭环，单向声明外部依赖。
- **`MDL902`（成员路径缺失）**：`federations.<scope>.local.path` 指向的路径不存在。修复：检查相对路径拼写并确保子模块/工作区已拉取；若允许非本地环境缺失，可配置 `missing: warn` 跳过并转为警告。
- **`MDL903`（挂载别名冲突）**：两个成员折叠出相同的别名、某别名是另一别名的目录段前缀、别名命中了主仓的现有顶层目录名，或成员路径位于主仓根目录及其上界。修复：调整成员目录结构或别名挂载路径以避免物理折叠歧义。
