# 诊断码速查手册（MDL001–MDL801）

MDLineage 报告的每个质量或结构问题均携带全局唯一的 `MDLxxx` 诊断码。诊断码与严重级别属于版本化的稳定契约，严重级别可通过 `mdlineage.config.yaml` 的 `diagnostics:` 块进行项目级覆盖。

相关文档：[`使用指南.md`](./使用指南.md)（功能全景）、[`配置指南.md`](./配置指南.md)（配置项说明）、[`命令行参考.md`](./命令行参考.md)（CLI 选项）。

---

## 2. 核心诊断码排查与修复指引

### MDL0xx：头部语法与解析
- **`MDL001`（未闭合）**：开头的 `---` 缺少配对的结束 `---`。修复：补齐闭合的 `---` 分隔线。
- **`MDL002`（YAML 损坏）**：YAML 存在缩进错误、包含 Tab 制表符等。修复：检查 YAML 缩进格式。
- **`MDL003`（缺少元数据）**：开启强制检查后文档缺少 Front Matter。修复：运行 `mdlineage fix --write` 自动注入基础骨架，或在 `mdlineage.manifest.yaml` 中旁路登记。

### MDL1xx：模式契约与字段
- **`MDL102`（缺少必填字段）**：缺少必填的 `id`、`kind`、`status` 或强关系的 `reason`。修复：运行 `mdlineage fix --write` 自动从词汇表中插入默认合法值。
- **`MDL103`（取值超出词汇表）**：例如将 `kind` 写成了词汇表之外的值。修复：修改为词汇表允许的类别。
- **`MDL104`（未知字段）**：`mdlineage` 块内拼写错误（如手误写成 `tpoics:`）。修复：纠正字段拼写或从块内移除。

### MDL2xx：文档内部语义与锚点
- **`MDL201`（证据锚点缺失）**：关系的 `evidence: "#some-anchor"` 在文档内找不到对应的标题。修复：更新为真实存在的标题 slug。
- **`MDL202`（重复关系）**：同文档内出现了两条完全相同的关系条目。修复：运行 `mdlineage fix --write` 自动删除重复项。
- **`MDL203`（同页锚点死链）**：正文中的 `[返回顶部](#top)` 找不到 `#top` 标题。修复：修正为文档实际存在的标题。

### MDL3xx：跨文件拓扑与血缘
- **`MDL301`（ID 重复）**：全仓有两篇文档使用了相同的稳定 `id`。修复：为冲突文档分配新的唯一 ID。
- **`MDL302`（目标丢失）**：关系声明的 `target: some.id` 在全仓索引中不存在。修复：纠正目标 ID 或补建缺失文档。
- **`MDL305`（循环依赖）**：禁止成环的关系类型（如 `supersedes`）形成了调用死循环。修复：解除环路上不合理的反向声明。
- **`MDL306`（引用废弃目标）**：活跃文档依赖了已被标记为 `deprecated` 的老旧文档。修复：迁移依赖至新替代文档，或推动更新。

### MDL4xx：超链接与宿主路径
- **`MDL401`（死链）**：相对路径链接目标文件不存在。修复：纠正路径或运行 `mdlineage move` 自动重写自愈。
- **`MDL402`（跨文档标题锚点丢失）**：链接 `[章节](./foo.md#bar)` 在目标文件内找不到 `#bar`。修复：对齐目标标题的 slug。
- **`MDL403`（宿主路径不可移植）**：使用了 `~/projects/...` 依赖本机的绝对路径。修复：改为工作区内的标准相对路径（`../`）。

### MDL5xx：目录规范与意图契约
- **`MDL502`（放错目录）**：例如将 `kind: spec` 的规范文件直接丢在要求 `kinds: [guide]` 的 `使用手册/` 下。修复：运行 `mdlineage move` 搬迁至匹配的目录。
- **`MDL503`（例外过期）**：在 `layoutExceptions` 中配置的临时豁免已过截止日期。修复：完成迁移并移除例外，或重新评估展期。
- **`MDL504`（约束超限）**：文件名不符合命名正则，或目录嵌套过深。修复：规范文件名或上提目录层级。
- **`MDL505`（孤儿文件）**：散落在未声明意图的根目录下。修复：归纳进对应的规范目录中。

### MDL6xx：行尾符卫生
- **`MDL601`（混合换行符）** 与 **`MDL602`（不符合策略）**：文件内夹杂 CRLF/LF，或与仓库策略不符。修复：运行 `mdlineage fix --write` 一键整仓归一。

### MDL8xx：生命周期与时效
- **`MDL801`（文档陈旧）**：文档超过 `staleAfterDays` 未曾更新。修复：复核正文事实后刷新 `updated_at` 时间戳；若已结项则标记 `status: archived` 移入 `历史归档/`。
